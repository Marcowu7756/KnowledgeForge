## 4. Experiment method (consume owns the clock)

Do not start from “what else can I build?”  
Start from “where did a real question get stuck?”

1. Related information in Archive?
2. Direct Retrieve?
3. Compose after retrieve?
4. Needed Artifact after compose?
5. **What exactly is missing?**
6. Is that a new Power?
7. Does that Power have Node I/O?
8. Combined with Knowledge, a **new** capability?

Only if 1–8 all hold: consider a slice.

Until then: Question → Retrieve → Compose → Use → Gap (A/B/C/D). Only D → SETV.
