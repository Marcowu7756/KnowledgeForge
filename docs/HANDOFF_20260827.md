## 1. 项目是什么

**KnowledgeForge** = 本地优先的 **PAILE**（Personal AI Learning Engine）知识编译器。

主链（冻结，勿改语义）：

```
Source → Harness → KnowledgeObject → ExpressionObject → Artifact
              ↓
    Reconstruct (Graph/Views) → Retrieve → Compose/Express
```

硬约束：

| 约束 | 含义 |
| --- | --- |
| Knowledge ≠ Expression ≠ Artifact | KO 不污染动画/音频格式 |
| Retrieve 单位 = 整卡 KO | 禁止 chunk-RAG 语义 |
| Local-first | Ollama + `models/`；cloud LLM 可选 |
| SETV 纪律 | 状态/失效/过渡/再确认；audit 未关项不宣称 FIXED |

## 6. UI v0.2 行为摘要

- **五段车间**：获取 → 沉淀 → 重组 → 检索 → 表达
- **长任务**：POST 返回 `job_id`，轮询 `GET /api/jobs/{id}`，前端进度条
- **预览**：`/api/preview` + 弹层；路径 sandbox 仅限 `data/`
- **打包**：`KF_ROOT` 环境变量（`app/config.py`）；frozen exe 不含 torch/whisper 等

API 要点：

| 端点 | 说明 |
| --- | --- |
| `POST /api/capture` … `compose` | 默认 `async_job: true` |
| `GET /api/jobs/{id}` | 进度与结果 |
| `GET /api/preview?path=` | MD/GIF/WAV 元数据 |
| `GET /api/preview/file?path=` | 媒体流 |

## 8. 外部生态：SETV / FactorLib / AShareLib

**共识（设计层，尚未编码）**：

这三套是个人专有知识库的**优质来源**，但应编译为 **分级 KO**，不是全量文档 RAG。

| 来源 | 适合沉淀为 KO | 不应进 KO |
| --- | --- | --- |
| SETV | 方法论、失效条件、状态转换、风险控制 | — |
| FactorLib | 因子契约、known gap、实验结论 | 原始参数、未公开策略 |
| AShareLib | A 股约束、观察合同、域边界 | 行情 raw、账户、路径 |

**受控访问（下一迭代 P0，当前未实现）**：

```yaml
classification: public | internal | restricted | secret
default_for_setv_factor_ashare: restricted
enforce_at:
  - ingest（打标 + 分区目录）
  - retrieve / compose（filter + 禁止 secret 进 LLM prompt）
  - git（secret/ restricted 默认不进 remote）
  - UI export / preview
```

建议 KO 字段（待实现）：

```yaml
access:
  classification: restricted
  source_project: factorlib   # setv | factorlib | asharelib
  export_policy: local_only
```

已有 SETV 方法论卡示例：`data/knowledge/methodology/setv_*.md`（index 已收录）。
