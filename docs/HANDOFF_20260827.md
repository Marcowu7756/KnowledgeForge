## 1. 项目是什么

**KnowledgeForge** = 本地优先的 **PAILE**（Personal AI Learning Engine）知识编译器。

主链（冻结，勿改语义）：

```
Source → Harness → KnowledgeObject → ExpressionObject → Artifact
              ↓
    Reconstruct (Graph/Views) → Retrieve → Compose/Express
```

硬约束：

| 约束 | 含义 |
| --- | --- |
| Knowledge ≠ Expression ≠ Artifact | KO 不污染动画/音频格式 |
| Retrieve 单位 = 整卡 KO | 禁止 chunk-RAG 语义 |
| Local-first | Ollama + `models/`；cloud LLM 可选 |
| SETV 纪律 | 状态/失效/过渡/再确认；audit 未关项不宣称 FIXED |

## 8. 外部生态：SETV / FactorLib / AShareLib

**共识（设计 + 编码）**：

这三套是个人专有知识库的**优质来源**，编译为 **分级 + 层级 taxonomy KO**，不是全量文档 RAG。

| 来源 | 适合沉淀为 KO | 不应进 KO |
| --- | --- | --- |
| SETV | 方法论、失效条件、状态转换、风险控制 | — |
| FactorLib | 因子契约、known gap、实验结论 | 原始参数、未公开策略 |
| AShareLib | A 股约束、观察合同、域边界 | 行情 raw、账户、路径 |

**Ingest CLI**（`app/ingest/ecosystem.py` + `taxonomy_registry.yaml`）：

```powershell
python main.py ecosystem ingest setv D:\fxtrading\setv\docs --dry-run
python main.py ecosystem ingest setv D:\fxtrading\setv\docs --limit 5
```

**Taxonomy 链**（纲举目张）：KO 字段 `taxonomy.path`，如 `专有知识 > SETV > 方法论 > 状态转换`；graph `--view taxonomy|contrast`；retrieve `--taxonomy-prefix`。

**Contrast 聚类（A8）**：KO 卡片 Relationship 中写 `- A vs B`（或 `对比`/`区别于` 等），reconstruct 生成 `contrast_cross_ko` 边；`--view contrast` 按 union-find 聚类展示跨卡对照组。

**受控访问（P0 — 已编码）**：

```yaml
classification: public | internal | restricted | secret
default_for_setv_factor_ashare: restricted
enforce_at:
  - ingest（打标 + 分区目录）          # ✅ default_access_for_ingest
  - retrieve / compose（filter + 禁止 secret 进 LLM prompt）  # ✅
  - git（secret/ restricted 默认不进 remote）  # ✅ data/restricted/ gitignore
  - UI export / preview                 # ✅ secret 卡 preview 拒绝
```

实现入口：`app/knowledge/access.py`；KO 字段 `access`；索引 `IndexRecord.classification`。
# Environment variables: `KF_ACCESS_MAX_RETRIEVE`（默认 `restricted`）、`KF_ACCESS_INCLUDE_SECRET=1` 才索引 secret。

**Access Policy（v0.1 骨架，2026-08-28）**：classification 定默认；KO 可挂显式 `policy`：

```yaml
access:
  classification: restricted
  source_project: setv
  export_policy: local_only
  policy:
    retrieve: true
    compose: local_only
    expression: controlled
    export: local_only
```

| classification | retrieve | compose | expression | export |
| --- | --- | --- | --- | --- |
| public | true | allow | allow | export_ok |
| internal | true | allow | allow | warning |
| restricted | true | local_only | controlled | local_only |
| secret | false | deny | deny | deny |

闸门：retrieve / compose（云端仍硬拦 restricted）/ expression（preview + animate/narrate；`controlled` 禁 external）/ export（骨架：`deny` 才禁）。原则：**restricted = 可工作的资产层；secret = 保险库**。

**LLM 双轨（冻结）**：默认即可选本机大模型（`ollama`）或云端外网大模型（`openai` / `gemini` / `deepseek`），用 `LLM_PROVIDER` 切换。  
`policy.compose=local_only` **不是**「系统只能用本机」，而是「该 KO 仅在当前选中本机模型时进入 compose；选云端时该 KO 被滤掉，云端仍可用 public/internal」。

KO 字段示例：

```yaml
access:
  classification: restricted
  source_project: factorlib
  export_policy: local_only
taxonomy:
  path: ["专有知识", "SETV", "方法论", "状态转换"]
```

已有 SETV 方法论卡示例：`data/knowledge/methodology/setv_*.md`（index 已收录；本地 data gitignore）。
